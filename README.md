# Xoai Aura Retreat - Hệ thống Quản lý Khu nghỉ dưỡng & Spa Trị liệu

### 📢 Lưu ý về mã nguồn (Disclaimer)
Đây là kho lưu trữ cá nhân hiển thị toàn bộ mã nguồn **Full-Stack (Backend & Frontend)** do tôi phát triển thuộc dự án **Xoai Aura Retreat**. Dự án hiện đang trong quá trình phát triển (In-progress) và hệ thống gốc được lưu trữ bảo mật trên GitLab của nhà trường. Repo này được công khai làm Portfolio cá nhân.

---

### 🏗️ Kiến trúc & Công nghệ sử dụng
- **Backend Core:** Java 17, Spring Boot, Spring Security, Spring Data JPA.
- **Frontend UI:** ReactJS (hoặc Thymeleaf), Bootstrap, Axios.
- **Database:** MySQL / PostgreSQL.
- **Tích hợp bên thứ ba:** VNPay Sandbox API, Google Calendar API.

### 📌 Các Phân hệ Tính năng Hệ thống (Đang phát triển)
1. **Module 1:** Xác thực (SSO) & Quản lý Hồ sơ Sức khỏe Nhạy cảm (Mã hóa dữ liệu theo Nghị định 356/2025/NĐ-CP).
2. **Module 2:** Đặt Gói Nghỉ dưỡng & Quản lý trạng thái Biệt thự thực tế.
3. **Module 3 (Lõi 1):** Hệ thống lên lịch Spa tự động (Thuật toán khớp đồng thời Chuyên viên & Phòng trống)[cite: 1].
4. **Module 4 (Lõi 2):** Quản lý chế độ ăn uống F&B, tự động lọc thực đơn theo hồ sơ dị ứng khách hàng[cite: 1].
5. **Module 5:** Kế toán trung tâm (Guest Folio), tổng hợp chi phí tự động & Tích hợp cổng thanh toán[cite: 1].
